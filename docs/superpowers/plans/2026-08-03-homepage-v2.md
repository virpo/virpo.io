# Homepage V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a complete, responsive `/v2/` homepage that preserves `/`, reuses the working toys, and applies the approved restrained-bento and pixel-art direction.

**Architecture:** Add a separate App Router page and CSS module. Reuse the existing interactive `FaceToy`, `SoundsToy`, `WindowSeatToy`, `StudyToy`, `BloomTicker`, and article data behind v2-only wrappers and selectors, so the original homepage stays behaviorally and visually unchanged. Store replaceable generated art under `public/assets/v2/` with prompts documented beside the implementation.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, CSS Modules, Vitest/Testing Library, Playwright, built-in image generation.

## Global Constraints

- Keep `/` unchanged.
- V2 lives at `/v2/` and is excluded from indexing while it is a preview.
- Peter's interactive face stays an exact square and remains cursor-reactive.
- Toy order is radio, Window Seat, Japanese Study.
- Radio, study, and bloom visuals are replaceable pixel-art assets with documented prompts.
- Latest writing uses readable editorial typography, meaningful excerpts, dates, reading time, and full-card links.
- Desktop and mobile must have one obvious reading order and no horizontal overflow.
